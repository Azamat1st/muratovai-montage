code copes without it). Licence texts for bundled third-party files are in `THIRD_PARTY_NOTICES.md` and `assets/fonts/LICENSES/`.

## Left out

| file / class | why | what the code does without it |
|---|---|---|
| a built-in style, other creators' reels, frames, stems, beat sheets; the author's own reels and plans | not part of the kit: every user makes their own style | never shipped; `fetch_reels.py` and `analyze_reference.py` keep them in the user's private profile folder (`raw/`, `work/`) |

## Fetched at run time, never bundled

| what | source | terms |
|---|---|---|
| brand logos | Simple Icons (`cdn.simpleicons.org`), Google favicon service | icons CC0; the marks belong to their owners |
| 3D emoji | Microsoft Fluent Emoji (GitHub) | MIT |
| GitHub cards, site screenshots, posts | GitHub, the sites themselves (Playwright) | third-party content: use as news/commentary does, follow platform rules |
| background-removal model | `npx hyperframes remove-background` (HyperFrames) | per HyperFrames (Apache-2.0) and its model |
| transcription, voice isolation, SFX generation | ElevenLabs API (`ELEVENLABS_API_KEY`) | the user's ElevenLabs plan terms |
| reference reels | Apify (`APIFY_TOKEN`) or yt-dlp | private analysis only; the user is responsible for the platform's terms |
