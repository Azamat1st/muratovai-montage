## Изменения форка

Этот пакет — форк оригинального `reels-montage` Игоря Косолапова (MIT, см. `LICENSE`); лицензия и авторство не менялись.
Изменения сделаны в двух заходах, оба остаются в силе:

- **Без OpenAI** (сентябрь 2026): распознавание речи (референсных роликов и своего дубля) — ElevenLabs Scribe
  (`scripts/transcribe.py`), а не OpenAI Whisper; разметку кадров (layout, план, графика, подписи) делает сам
  агент по контрольным листам, а не модель зрения OpenAI (`scripts/reference/vision_tags.py`); измерение звука —
  локальный Demucs (`--two-stems=vocals`), без OpenAI/OpenRouter классификатора. Добавлены типы графики `ui`
  (тёмные экраны приложений) и `comment` (окно комментария → уведомление Instagram) и стиль подписей `wide`
  (`caption_face: "wide"`). Тесты — `scripts/tests/` (61 тест на момент этого форка).
- **Нейтральность к агенту и пути** (2026-09-27): пакет работает и в Claude Code, и в Codex CLI без правок. Тексты
  называют инструмент просмотра картинок обобщённо (Claude Code — `Read`, Codex — `view_image`); убраны инструкции звать
  субагентов для разметки кадров — разметка идёт по одному ролику за раз в текущей сессии. Корни для упакованных стилей
  (`montage-<handle>`) берутся из переменной `REELS_STYLES` (список через `:`, по умолчанию — папка скиллов Claude Code);
  `scripts/reference/make_skill.py` без `--dest` использует первый такой корень. Скрипты находят свою папку через `__file__`.
  Метод — процедуры A и B, справочники, графика, звук, ритм и проверки — не менялся.
